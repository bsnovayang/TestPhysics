# TestPhysics

2D 平台動作遊戲原型，特色是物理解謎（類洛克人、東方月神夜）。玩家發射「網」展開物理場域，改寫區域內的重力與時間。

純前端 HTML / JavaScript（Canvas 2D、ES Modules、自製物理），不需要建置步驟。

## 執行

ES Modules 必須透過 HTTP 載入，不能直接雙擊 `index.html`。

- **XAMPP**：把專案放在 `htdocs/TestPhysics`，啟動 Apache，開啟 `http://localhost/TestPhysics/`
- **其他方式**：在專案資料夾執行任何靜態伺服器，例如 `npx serve` 或 `python -m http.server`

開發用網址參數：`?autostart` 跳過開始畫面，`?room=N` 直接進入第 N 個房間。

## 水的四種版本（比較用）

**預設是 Noita 風像素水（正式版）**，其他版本保留下來比較。開始畫面可以直接切換，或使用下列網址：

| 版本 | 網址 | 說明 |
|---|---|---|
| 原版（格子水） | `index.html?water=cell` | 每一格存一個水量，流動可預測 |
| 粒子版 | `index.html?water=particle` 或 `experiments/particle-water/` | 用粒子模擬水流，再換算回格子，其他系統直接沿用 |
| 原版＋粒子特效 | `index.html?water=fx` 或 `experiments/water-fx/` | 運作和原版相同，畫面加上水珠、水花、水面波紋 |
| **Noita 風像素水（正式）** | `index.html` 或 `experiments/pixel-water/` | 落沙模擬：每 2×2 px 一格，水、蒸氣、熔岩都是像素；亂數固定種子，同樣的操作結果相同 |

建議在房間 G（冰與水）和 H（蒸氣）比較，也可以按住 N 倒水、B 噴蒸氣。

## 操作

| 按鍵 | 動作 |
|---|---|
| A / D | 移動（重力朝側面時改用 W / S） |
| Space | 跳躍 |
| Shift | 衝刺（空中一次） |
| 滑鼠左鍵 | 空氣砲（按住連射，有後座力） |
| 右鍵、Q、E、R、F | 技能欄 1～5，對準游標施放 |
| X／中鍵 | 解除所有場域 |
| Tab | 裝備選單 |
| Esc | 暫停 |
| H | 操作說明 |
| L | 選擇關卡（開始畫面也可以直接選） |
| / | 顯示／隱藏房間提示（預設隱藏） |

### 技能的三種施放方式

| 游標指向 | 操作 | 結果 |
|---|---|---|
| 空地或牆 | 按一下 | 場域固定在那裡，3 秒後消失 |
| 箱子、敵人 | 按一下 | 場域附著在對方身上，跟著移動 |
| 自己（或按住 C） | **長按** | 場域附著在自己身上，持續消耗 MP，放開就結束 |

遊戲中游標旁會顯示目前的施放方式。

### 除錯

| 按鍵 | 動作 |
|---|---|
| 1～9、0、-、=、、;、'、, | 把技能直接放到右鍵（0 閃現、- 傳送門、= 重力抓取、 磁力、; 時間倒轉、' 向量反射、, 電磁加速） |
| [ / ] | 上一個／下一個房間 |
| T | 重置房間 |
| G | 顯示碰撞框與數值 |
| M | 整體慢動作 |
| F2 | 開關除錯參數面板（預設隱藏） |
| 按住 B／N | 在游標位置噴蒸氣／倒水 |
| K | 對游標下的敵人造成 3 點傷害（無視護甲） |
| J | 魔王直接進入第二階段 |
| I | 玩家無敵（尖刺、掉落仍會回到入口） |

除錯參數面板可以即時調整數值（需要網路，從 CDN 載入 lil-gui）。

## 美術

像素風：遊戲畫在 640×360 的畫布上再整數倍放大；精靈與圖塊在 `js/pixel/art.js`（做法參考 GriMon）。畫布文字使用 [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font) 12px（OFL 授權，見 `fonts/`）。
