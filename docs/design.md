# TestPhysics 企劃文件（原型階段）

> 最後更新：2026-10-15
> 狀態：原型完成 M1～M7（重力、時間、空間三棵技能樹的主要技能），可以試玩

## 0. 原型使用方式
- 啟動 xampp 的 Apache，開啟 `http://localhost/TestPhysics/`（ES Modules 不能直接雙擊 html 開啟）
- 開發用網址參數：`?autostart` 跳過開始畫面、`?room=N` 直接進入第 N 個房間
- 程式結構（`js/`）

| 檔案 | 內容 |
|---|---|
| `config.js` | 所有可調整的數值（除錯面板直接修改這裡） |
| `skills.js` | 技能定義、預設裝備 |
| `fields.js` | 場域與疊加規則 |
| `body.js` | 物理物體的共用邏輯：碰撞、重力方向、摩擦 |
| `player.js` | 角色控制、空氣砲、施放技能 |
| `objects.js` | 箱子、移動平台、刀片、壓碎機關、開關 |
| `enemies.js` | 測試用敵人（步行兵、跳躍兵、飛行兵、重裝兵、砲台、雷射兵） |
| `gravity-enemies.js` | 重力區的敵人（重壓兵、氣球兵、倒吊兵、重力盾兵）與重力魔王 |
| `projectiles.js` | 網、空氣砲彈、敵人子彈 |
| `portals.js` | 傳送門：開門、穿過時的位置與速度轉換 |
| `light.js` | 光線追蹤（反射、折射、彎曲、傳送門）、雷射發射器、鏡子箱 |
| `water.js` | 格子水、蒸氣、熔岩的流動、結冰、融化、沸騰、凝結、熔岩凝固成石頭 |
| `volcano.js` | 噴發口、飛行中的熔岩塊、火山彈、熔岩源與水源 |
| `rooms.js` | 房間的 ASCII 地圖（直接編輯就能改關卡） |
| `legend.js` | 地圖圖例：每個字元代表什麼、怎麼建立（新增物件時在這裡登記一個字元） |
| `abilities/` | 各能力的邏輯，掛到 World 上：定向重力的瞄準、重力抓取、向量反射、電磁加速、時間倒轉、閃現、洗腦、附身 |
| `world.js` | 房間載入、更新順序、受傷與重置 |
| `render.js` | 繪製的主流程（畫在 640×360 的低解析度畫布，最後整數倍放大） |
| `render/` | 各類別的畫法，掛到 Renderer 上：地形、物件、角色與敵人、場域、能力特效、介面 |
| `pixel/art.js` | 像素美術：像素緩衝、字元點陣圖、自動描邊、烘焙快取；主角、敵人、地形、箱子、門、尖刺的圖 |
| `main.js` | 主迴圈、除錯按鍵、裝備選單 |

- 尚未實作：斜坡、技能樹、音效、手把、閃現穿牆（已有除錯開關）、會移動的傳送門

## 0.1 定位與方向（2026-10-15 決定）

| 項目 | 決定 |
|---|---|
| 整體定位 | 比較接近 **Trine 4**：精心設計的物理解謎平台遊戲，鼓勵多種解法；但結構是類銀河惡魔城，只有一個角色（改寫物理定律） |
| 模式 | **單人**（多人合作之後再考慮：三棵技能樹可以分給不同玩家） |
| 美術 | **像素風**（和像素水搭配；參考東方月神夜的像素美術） |
| 水 | **Noita 風像素水為正式版本**（預設）；原版格子水、粒子版、特效版保留比較 |
| 隨機 | 會影響玩法的亂數**固定種子**：像素水依房間地圖決定種子；火山彈、熔岩塊用每個房間固定的種子；同樣的操作永遠得到同樣的結果（已驗證：同一段操作跑兩次，所有像素與物件位置完全相同） |

### 和 Noita 的區隔
- 核心動作是**改寫規則**（重力方向、時間流速、空間連接），不是丟法術、加入材質；Noita 沒有時停、反重力、傳送門、光線折射這類玩法
- **可預測的謎題**（所以亂數要固定），不是混亂與失控
- **手工設計的類銀河惡魔城**，不是隨機地圖與永久死亡
- **地形不可破壞**，只有特定的變化（結冰、凝固成石頭）
- 有完整的**故事與角色**
- 洛克人式的**動作手感**與魔王戰
- 像素水只是畫面與物理的技術；東方月神夜也是像素美術，但它的水是畫好的像素圖，不是逐像素模擬

## 1. 遊戲概念

- 類型：2D 平台動作遊戲 + 物理解謎（類銀河惡魔城）
- 參考作品：洛克人系列（操作手感、魔王給能力）、東方月神夜（時間操作）、Portal（傳送門）
- 核心玩法：玩家發射「網」，在指定位置展開圓形**物理場域**，場域內的物理常數會被改寫，用來解謎和戰鬥
- 平台：純前端 HTML/JS，以 xampp 提供靜態檔案

## 2. 場域系統

### 2.1 施放方式（蜘蛛網式）
- 網朝滑鼠游標直線飛行，**到達游標位置就展開**
- 途中碰到牆壁或敵人會提早展開
- 有最大射程（初始約 10 格），游標超出射程時，在射程極限處展開
- 網在飛行中**不受其他場域影響**

### 2.1.1 附著
網擊中什麼，場域就附著在什麼上面，並跟著它移動：

| 目標 | 效果 |
|---|---|
| 自己 | 等於改變自身狀態，例如減重跳遠、反重力走天花板 |
| 箱子 | 例如反重力箱子會一路往上升，像氣球 |
| 敵人 | 例如反重力敵人會飄走 |
| 空地或牆壁 | 固定在原地（原本的行為） |

- 對自己施放：**游標指在自己身上**，或**按住 C**
  - 不使用 Ctrl：瀏覽器中 Ctrl+W 會關閉分頁（W 是移動鍵），Ctrl+R 會重新整理（R 是技能鍵）
- 附著的場域用虛線外框，和固定場域區分；預覽時會框出將被附著的對象
- 附著對象消失時，場域留在原地
- 定位：固定場域偏向改造環境、解謎；附著場域偏向強化自己、控制目標

### 2.1.2 自身附著的平衡
自身附著（尤其是反重力、定向重力）太強：場域跟著自己，永遠不會離開範圍。採用的限制方式：

| 方式 | 內容 | 故事上的解釋 |
|---|---|---|
| **持續消耗** | 按住技能鍵維持，啟動時扣一般消耗，之後每秒 25 MP；放開或 MP 耗盡就結束；維持期間 MP 不回復 | 把線織在自己身上，必須一直拉住它（和東方月神夜的時停相同） |
| **隨進度解鎖** | 前期只能放固定場域，「自身附著」是技能樹的節點 | 女神的力量恢復到一定程度，才能把線直接織在勇者身上 |

- 不採用「勇者錨點」（自身效果打折）
- 維持型場域不佔用場上數量上限，也不會被新放的場域擠掉
- 原型中可以用除錯面板的「自身附著已解鎖」開關，模擬前期的體驗

### 2.1.3 關卡設計原則（因應自身附著）
- **解鎖前的關卡，必須只靠固定場域就能過**
  - 已驗證：房間 A 的尖刺坑，在坑的上方預先放無重力或減重，跳進去就能滑過（一般跳和空中衝刺都過不了）
- **解鎖後**：回到舊區域時，可以用自身附著抵達以前到不了的地方，例如隱藏道具、捷徑（類銀河惡魔城的回頭探索）
- 後期關卡用規則封印區、天花板陷阱、強風等方式，避免自身附著直接解掉所有地形

### 2.2 場域規格（初始值，可在除錯面板調整）
| 項目 | 初始值 |
|---|---|
| 形狀 | 圓形 |
| 半徑 | 約等於角色身高（2 格 = 32 px） |
| 持續時間 | 3 秒 |
| MP 消耗 | 初始 MP 上限的 1/10 |
| 場上最多數量 | 2 個（超過時取代最舊的） |

- 判定方式：**物體中心點**在圓內才算受影響
- 玩家本身也會受場域影響
- 時停場域內的玩家不會完全停住，而是以 0.2 倍速移動（避免卡死）

### 2.3 疊加規則
每個場域都視為一個修正值：

| 類型 | 技能 | 疊加方式 |
|---|---|---|
| 倍率型 | 減重 ×0.5、無重力 ×0、反重力 ×-1、減速 ×0.5、時停 ×0、加速 ×2 | 相乘 |
| 方向型 | 定向重力、點重力 | 向量相加 |

- 計算順序：**先加總方向，再乘上所有倍率**
  - 重力 = （方向型向量總和；沒有方向型時為預設的向下重力）× 重力倍率乘積
  - 時間 = 時間倍率乘積
- 上限：加速最多 3 倍；重力大小設上限，防止穿牆
- **場域阻力**（反重力 12、點重力 4）：只削減「逆著場域重力方向」的速度
  - 原因：沒有阻力時，物體在反重力場域邊緣會一直上下彈跳
  - 順著重力衝出場域時不受影響，所以反重力電梯保有衝力；掉回場域時才被減速，彈跳逐漸變小
  - 實測：均勻阻力會讓電梯的成功率從 9/10 掉到 4/10，方向性阻力則維持 9/10
- 視覺：重疊區域要混色，或用明顯的邊框標示

### 2.4 MP
- 會緩慢自然回復
- 敵人掉落的回復道具作為額外補充

---

- **靜止回復**（2026-10-16）：站在地上完全不動、不按任何操作鍵、也沒有在維持技能（自身附著、抓取、向量反射、附身）時，靜止 1.5 秒後 MP 回復開始加速，1 秒內從每秒 3 加速到每秒 30（0 到全滿約 4.7 秒）
  - 附近 10 格內有敵人時，要靜止 3 秒才開始加速；被打到後 3 秒內不會加速
  - 目的：解謎時不用乾等 MP；戰鬥中很難站著不動，所以不適合拿來打架。做成被動，不佔按鍵也不佔技能欄
  - 畫面：加速中角色身邊有往上飄的藍色光點，MP 條變亮；數值可以在除錯面板（F2 → 場域）調整

## 3. 能力與技能樹

### 3.1 三棵技能樹
**重力**
```
Lv1 減重（0.5g）
 └ Lv2 無重力（0g）
    └ Lv3 反重力（-g）
       ├ Lv4a 定向重力
       └ Lv4b 點重力／黑洞
```

**時間**
```
Lv1 減速（0.5x）
 └ Lv2 強減速（0.2x）
    ├ Lv3a 時間停止
    └ Lv3b 時間加速（對自己使用＝加速 buff）
       └ Lv4 倒轉（技術成本高，放後期）
```

**空間**（後期，第一版原型不做）
```
Lv1 短距離閃現
 └ Lv2 傳送門對（保留動量）
    ├ Lv3a 傳送門方向旋轉
    └ Lv3b 空間壓縮
```

### 3.1.1 空間技能規格

**閃現**
- 對準游標瞬間移動，距離上限約 5 格
- 初始不能穿牆：目標被擋住時，停在牆前面（之後解鎖穿牆）
- 閃現後**保留原本的速度**（慣性）

**傳送門**（和 Portal 相同）
- 傳送門是「**空間的裂縫**」，固定在牆面、地板、天花板上，**不受任何場域影響**
  - 通過門的物體照樣受出口附近的場域影響
  - 之後可以擴充：門開在箱子上就跟著箱子移動（沿用附著系統）
- **任何牆面**都可以開門：網需要直線飛到那裡，所以玩家必須能看到那個位置
- 門的大小 2 格（牆上 2 格高、地板或天花板 2 格寬），需要連續 2 格可用的牆面
- 用網施放：第 1 發是入口（藍）、第 2 發是出口（橘），第 3 發取代最舊的門；只有一個門時沒有作用
- **什麼都能通過**：玩家、箱子、敵人、子彈、空氣砲彈、網
  - 網可以穿過門，在另一邊展開場域；場域本身不會透過門延伸
- 動量轉換：速度大小不變，方向轉成出口面向的方向；出口給一個最低射出速度，避免卡住
- 持續 30 秒；兩個門各消耗一次 MP
- 原型簡化：物體中心穿過門的瞬間就傳送，不做「身體一半在兩邊」的畫面；允許地板門對天花板門的無限掉落（受終端速度限制）

### 3.2 解鎖制度
- **魔王或探索**：取得新能力型態的「解鎖資格」
- **等級點數**：自由配點，可以重置（細節之後規劃）
- 量變的升級項目：場域大小、持續時間、MP 消耗、同時存在的數量、射程、蓄力

### 3.3 移動能力（和場域技能分開解鎖）
跳得更高 → 二段跳 → 蹬牆跳 → 空中衝刺

## 4. 操作（鍵盤＋滑鼠，雙搖桿模式）

| 動作 | 按鍵 |
|---|---|
| 左右移動 | A / D |
| 往上（門、梯子、往上看） | W |
| 蹲下／從薄平台往下跳 | S |
| 跳躍 | Space |
| 衝刺 | Shift |
| 空氣砲（基礎攻擊） | 滑鼠左鍵 |
| 技能欄 1～5 | 滑鼠右鍵、Q、E、R、F |
| 解除所有場域 | X（或滑鼠中鍵） |
| 裝備選單 | Tab |
| 暫停 | Esc |
| 除錯：切換技能 | 數字鍵 1～9、0、-（只在原型使用） |

- 技能採 POE 式裝備：從已解鎖的技能中挑選放進技能欄（初始 3 格，隨等級增加到 5 格）
- 按下快捷鍵就立即對游標施放
- 可以隨時在暫停選單更換裝備
- 關卡設計規則：一個謎題需要的技能數量，不能超過玩家當時擁有的技能欄數量
- 按鍵之後要開放玩家自訂
- 手把之後再支援（待解決：右搖桿只能決定方向，無法決定距離）

### 4.1 各施放型態的操作
| 型態 | 技能 | 操作 |
|---|---|---|
| 投射型 | 減重、反重力、減速、時停、點重力 | 按下 → 網飛向游標並展開 |
| 自身型 | 時間加速 | 按下 → 直接作用在自己身上 |
| 閃現 | 短距離傳送 | 按下 → 瞬移到游標位置（有距離上限，目標位置必須是空的） |
| 成對型 | 傳送門 | 第 1 次按＝入口，第 2 次按＝出口，之後再按就取代最舊的 |
| 需要指定方向 | 定向重力 | 按住決定位置 → 拖曳決定方向 → 放開展開（原型可以簡化成：方向＝角色到游標） |

### 4.2 瞄準輔助
- 自訂準星
- 從角色到準星的直線預覽，終點顯示場域展開後的輪廓
- 顯示射程範圍

## 5. 角色

### 5.1 跳躍
- **起跳速度固定**，所以在低重力下會自然跳得更高
- 跳躍方向以當下的重力方向為準（反重力時往「下」跳）
- 加入土狼時間（約 0.1 秒）和跳躍預輸入

### 5.2 空氣砲（基礎攻擊）
- 朝游標發射，不消耗 MP，有射速限制
- 傷害低、擊退中等；擊退量 = 衝擊力 ÷ 質量
- 每次射擊都有後座力：在地面上會被摩擦力抵消；在空中或無重力時就會明顯推動玩家
- 和場域的組合：無重力中遠距離運送箱子、後座力當空中推進、把敵人子彈吹歪
- 之後的升級：蓄力砲、散射、射程延長、時停中累積衝擊力（進階）

---

## 5.4 受傷
- 受傷後有 **1.5 秒無敵時間**（角色閃爍），期間不會再受傷
- 受傷後有 **0.35 秒硬直**：不能移動、跳躍、衝刺，讓擊退真的把角色推離敵人
  - 原因：原本擊退在約 0.1 秒內就被玩家的操作抵消，按著方向鍵時會一直黏在敵人身上，無敵時間一結束又被打
- 碰到尖刺或掉出畫面：扣 2 HP 並回到入口，MP 回滿

## 5.5 戰鬥設計

### 5.5.1 空氣砲的傷害分級（方案 D）
空氣砲的推動、推進功能永遠保留，只有「傷害」依對象分級：

| 對象 | 空氣砲的效果 |
|---|---|
| 小怪 | 可以打死，但傷害偏低（步行兵 3 發） |
| 重裝敵人 | 打不痛，只能推 |
| 魔王 | 打不痛，但可以推動、打斷動作、反彈魔王的子彈 |

- 故事上的解釋：魔王是用**被封印的規則**做成的兵器，一般的力量傷不了它，只能用規則本身對付它

### 5.5.2 撞擊傷害
- 物體撞到牆、地面或其他物體時，**速度超過門檻**（320 px/s，約從 3.6 格高掉下來）才會受傷，超過越多傷害越高（每 50 px/s 算 1 點）
  - 門檻要高於跳躍兵的起跳速度（270），否則它每次落地都會自傷
- 物體互撞以**相對速度**計算，再乘上撞過來那一方的**質量**；之後依質量交換動量（部分反彈）
  - 實測：箱子從高處砸到步行兵 6 點；重裝兵（質量 5）以 500 px/s 撞上步行兵 15 點
- **玩家不受撞擊傷害**（女神的保護），避免用反重力或傳送門高速移動時誤傷自己
- 自然產生的玩法：反重力送上天再摔下來、傳送門射出的箱子變成砲彈、時停中累積衝擊後釋放
- 數值都可以在除錯面板（F2）的「撞擊傷害」分頁調整；受傷時會顯示傷害數字

### 5.5.3 撞擊與尖刺的分工
| | 撞擊傷害 | 尖刺 |
|---|---|---|
| 條件 | 需要速度 | 只需要位置 |
| 技巧 | 偏向操作：把東西加速 | 偏向解謎：把東西推到對的地方 |
| 主要用途 | 戰鬥中的攻擊手段 | 對玩家的地形威脅、關卡中的危險區域 |

- 有了撞擊傷害，殺敵不再依賴尖刺
- 重裝兵**不怕撞擊**，只能用尖刺或坑洞處理；但它很重，被甩去撞別人時傷害很高
- 方向：利用不同的抗性與弱點，設計需要不同解法的敵人

### 5.5.4 魔王戰原則：魔王自己提供打倒它的手段
魔王免疫空氣砲，所以魔王房間一定要有「彈藥」：

| 彈藥來源 | 例子 |
|---|---|
| 魔王召喚的小怪 | 用反重力把小怪甩向魔王；用傳送門讓小怪從魔王頭上掉下來 |
| 魔王的投射物 | 時停魔王丟出的岩石再打回去；子彈穿過傳送門打回魔王 |
| 場地機關 | 壓碎機關、會掉落的吊燈、可以推的大箱子 |
| 魔王本身 | 反重力讓它撞上天花板；用傳送門讓它從高處掉下來 |

- 魔王攻擊越兇，玩家手上的彈藥就越多，形成「先閃躲，再反擊」的節奏

### 5.5.5 重力區的敵人（2026-10-16，原型已實作，房間 K）
每一種都有一個用重力技能才好處理的弱點，但都不只一種解法。

| 敵人 | 地圖字元 | 行為 | 弱點（解法） |
|---|---|---|---|
| 重壓兵 | `p` | 很重，空氣砲推不動也打不痛；靠近時跳起來重踩，震波打到 4 格內站在地上的玩家 | 怕摔：反重力讓它撞天花板，場域消失後再摔回地面；減重時它跳得更高，場域一消失就從高處摔下 |
| 氣球兵 | `b` | 浮力剛好抵消正常重力，用螺旋槳維持高度；飄到玩家正上方時丟炸彈；空氣砲打不破，只會把它推開 | 重力變小時浮力就贏了：無重力或反重力讓它一路飄上去撞破（撞擊速度超過 150 就破）；減重不夠（螺旋槳還撐得住） |
| 倒吊兵 | `u` | 自己的重力是反的，走在天花板上，丟石頭打正下方的玩家；待在高處，空氣砲射程不夠 | 反重力讓它的重力變回向下，從天花板摔到地上；場域結束後又摔回天花板 |
| 重力盾兵 | `g` | 身邊有一圈往外推的重力盾（半徑 32，推力 2 倍重力）：從外面射進來的空氣砲和網都會被彈開，玩家也走不進去；它自己不受盾影響 | ① 把重力干擾器推到它旁邊，盾就失效 ② 先在它要走的路上放點重力，把它吸住，點重力和盾互相抵消 ③ 閃現進盾裡面，從裡面發射的空氣砲不會被彈開 |

- 重力盾和玩家的場域分開計算：不佔場上數量、不會被解除，疊加在原本的重力上（不會取代它）
- 盾被抵消的判斷：同一點所有點重力加總後，剩下的推力不到盾本身的一半，就不會彈開

### 5.5.5.1 施放與時停的調整（2026-10-16 試玩回饋）
- **定向重力改成 LOL 式施放**：按住技能鍵，網飛到游標的位置當起點（點在物體上就附著）；按住期間移動游標決定方向（畫面上有箭頭），放開按鍵時確定。場域展開後、放開之前方向會即時跟著游標改變——附著在物體上時，等於可以一路導引它。游標指在自己身上時仍是自身附著
  - 原因：原本方向固定為「角色 → 游標」，附著在鐵塊上時鐵塊只會往遠離角色的方向飛，幾乎不可能瞄準魔王
- **時停會累積施加的力**（曠野之息式）：被時停的物體挨的空氣砲，力量會存起來，時停結束時一次釋放。畫面上從物體畫出累積的箭頭：力道越大越長、越粗、越亮（時間系的藍色到白色；紅色保留給「加熱」）
  - 空氣砲在時停場域裡和玩家一樣最低保有 0.2 倍速度，才打得到被時停的物體（原本空氣砲進入時停場域也會停住，只是時停結束時一起打中）
  - **附著的時停只凍結目標本身**（2026-10-16 定案，曠野之息式）：旁邊的東西照常動。撞上被時停物體的速度超過 200 時，撞擊的動量也會累積在它身上（依質量換算）。畫面上附著時停只畫一個貼著目標的小圈
  - 放在空地上（不附著）的時停維持範圍效果：範圍內的東西都會凍住（時停子彈再踩上去、凍住熔岩柱等玩法不變）
- **鐵塊會碎**：撞到魔王或敵人造成傷害時一定碎；撞牆、地面、天花板的速度超過 520（約從 9 格高掉下來）也會碎；原本 400，但從磁力吸住的高度掉下來就會碎，倒轉的謎題做不了。魔王會一直補鐵塊，所以不會沒彈藥，但每一發都要瞄準（實測：玩家不動 40 秒，魔王丟出 11 個，碎了 8 個）

### 5.5.5.2 新能力：重力抓取、磁力、時間倒轉（2026-10-16，原型已實作，房間 M）
| 能力 | 系 | 操作 | 規格 |
|---|---|---|---|
| 重力抓取 | 重力 | 游標指著物體按住技能鍵：抓起來，移動游標搬運，放開時保留速度（甩一下就能丟出去） | **分三級**（見下表）；抓住時每秒 15 MP、MP 不回復；跟隨速度最高 420（超過撞擊門檻，丟敵人去撞牆會受傷）；不能抓自己腳下的東西（避免踩著飛）；中間不能被牆擋住；重力干擾器範圍內會放開 |
| 磁力 | 重力 | 和一般場域一樣發射網展開（可附著） | 半徑 4 格；只吸引金屬（鐵塊、重裝兵、重壓兵），2 倍重力，**疊加**在原本的重力上（所以吸得住天花板上的鐵塊）；木箱、玩家不受影響 |
| 時間倒轉 | 時間 | 發射網，一定要打中物體 | 物體沿著過去 8 秒的路徑倒退回去（2 倍速播放）；倒退中是實心的，站在上面會被載著走（曠野之息續作的「倒轉」）；最近沒有移動過的物體不能倒轉（退回 MP）；時間干擾器範圍內不能用 |

- **重力抓取的等級**（2026-10-16 試玩回饋：「可以抓這麼遠也太 OP」，改成升級制）：

| 等級 | 距離 | 最大質量 | 抓住後 |
|---|---|---|---|
| Lv1（基礎，原型預設） | 2 格（肩膀到物體最近的邊） | 1：木箱、一般敵人 | 固定在角色面前，跟著角色走；游標只決定在角色周圍的哪個方向（例如舉在頭上跳上台階） |
| Lv2 | 5 格 | 2：加上鐵塊 | 跟著游標移動 |
| Lv3 | 10 格 | 3 | 跟著游標移動（隔空搬運、遠距離投擲） |

  - 鐵塊要 Lv2 才抓得動，所以重力魔王的剋制效果會隨升級變強
  - 自己抓著的東西不會擋住自己；角色走遠或物體被牆卡住超出距離時會放開
  - 除錯面板（F2 → 測試）可以切換等級；之後由技能樹升級
- 設計重點：抓取是 Trine 法師式的搬運；倒轉讓「把東西弄掉了」變成可以利用的資源（先讓它掉下去，再搭著它回去）；磁力讓鐵塊和金屬敵人有自己的特性
- 技術：每個物體記錄最近 5 秒的位置；被抓住的物體不受重力；被時停的物體被撞時把動量存進去

### 5.5.5.3 向量反射與電磁加速（2026-10-16，原型已實作，房間 N、O；靈感來自科學側超能力，名稱與設定為原創）
**向量反射**（新的「向量」系，橘色）
- 按住技能鍵：角色周圍出現半徑約 2 格的反射場，放開就結束
- 消耗：啟動 10 MP；維持每秒 10 MP（維持期間 MP 不回復）；每反射一發子彈 3 MP；反射雷射時每秒 15 MP；擋下一次接觸傷害 3 MP；彈開衝過來的物體依力道 2～20 MP
- 冷卻：結束後 3 秒；MP 用光被迫結束時 5 秒
- 子彈和雷射**原路彈回**發射者（子彈變成我方子彈；雷射反射後連雷射兵自己也打得到）；衝過來的箱子、敵人照物理反彈；貼著的敵人被推開；反射期間不受接觸傷害
- 不反射重力、地面、自己的場域；尖刺和掉落仍會回到入口
- 數值調整：一開始照討論用維持 20／子彈 5／冷卻 4 秒，模擬時 100 MP 只撐 4 秒、30 秒才能用一次，房間打不完，所以放寬

**電磁加速**（重力系，和磁力同一系）
- 游標指向身邊約 3 格內的金屬物體（質量 2 以下，目前是鐵塊）按技能鍵：朝游標方向以 900 的速度射出（超過一般速度上限 600），前 0.5 秒不受重力、直線飛行
- 每次 25 MP，冷卻 2 秒；撞到敵人造成撞擊傷害（打魔王也算，一次最多 3），鐵塊照規則碎掉
- 特效：發射時從角色到物體一道閃電，飛行路徑留下青白色的鋸齒閃電
- 鐵塊生成器（地圖字元 `N`）會補鐵塊，彈藥不會用完

**其他**
- 技能冷卻：技能欄顯示暗色進度條與剩餘秒數；維持中的向量反射有橘色外框
- 修正舊 bug：站在平台上的砲台往下打時，子彈一生成就碰到腳下的平台而消失（房間 J 也有這個問題）。子彈剛射出的 0.1 秒不會被地形擋住
- 房間可以設定 `openWhen: 'enemies'`：打倒所有敵人才開門

### 5.5.5.4 洗腦（2026-10-16，原型已實作，房間 P；新的「精神」系，粉紅色）
- **施放**：游標指著敵人按下，發射網，打中的敵人變成自己人（粉紅色外框、頭上一顆愛心）
- **維持**：每控制一隻，每秒消耗 6 MP；MP 用光時全部清醒，變回敵人
- **數量上限**：分三級（1／2／3 隻，預設 1；除錯面板可以切換），超過上限時最早控制的那隻清醒；魔王無效
- **自己人**：攻擊 260 px 內最近的敵人，用它原本的攻擊方式（砲台開火、雷射兵發射雷射、重壓兵重踩、氣球兵丟炸彈……），射出的子彈算我方；撞到敵人造成接觸傷害；不會攻擊玩家，玩家的空氣砲打到它只會推開
  - 敵人也會攻擊自己人（玩家和自己人中誰近打誰），敵人的子彈也打得到自己人；**自己人被打死就沒了**
  - 自己人的重力盾：不推玩家、不彈開玩家的網和空氣砲，改成彈開敵人的子彈（移動的護盾）
- **指令**：游標不在敵人身上時按洗腦 = 下指令，自己人走到游標的位置待命（不發射網、不耗 MP；指令優先於自動攻擊）；對自己人再放一次 = 恢復跟隨（沒有對手時跟在玩家身邊）
  - 一開始做成「網打到地面才下指令」，但網很難穿過 1 格高的隧道口，改成直接用游標位置
- 附身另外做成獨立技能（見 5.5.5.5）

### 5.5.5.5 附身（2026-10-16，原型已實作，房間 Q；精神系，獨立技能）
- **施放**：發射網，打中敵人就附身（魔王無效），不需要先洗腦
- **本體被時間凍結**：留在原地、被時停泡泡包住，無敵，敵人也不會瞄準它（敵人改成攻擊被附身的敵人和自己人）
  - 為什麼：如果本體會被打，每個用到附身的房間都得另外設計「本體藏身處」，關卡會被綁住
  - 不做「靈魂出竅、解除時出現在敵人的位置」：附身會變成移動技能，怪物通道就形同虛設
- **操作**：A／D 移動、空白鍵跳；會飛的（飛行兵、氣球兵）W／S 上下；左鍵朝游標發動它的攻擊：砲台開火、雷射兵集氣後發射（瞄準游標）、重壓兵跳起來重踩、氣球兵丟炸彈、倒吊兵丟石頭、重力盾兵開火；其他靠接觸傷害。跳躍兵跳得比玩家高
- **結束**：再按一次技能鍵或 Esc 回到本體；MP 用光、被附身的敵人被打倒時強制回到本體。結束後那隻敵人恢復成敵人並暈眩 1 秒，技能冷卻 3 秒
- **消耗**：每秒 10 MP（附身期間 MP 不回復）

**新機關**
- **怪物通道**（地圖字元 `E`）：紅色光柵，只有敵人能通過；玩家和箱子過不去；網、子彈、雷射、水都能穿過
- **按鈕**（地圖字元 `F`）：踩過一次就鎖住。附身期間本體不能動，用壓板的話，一解除附身敵人就會走開、門又關上，所以附身的謎題用按鈕

### 5.5.6 重力魔王（2026-10-16，原型已實作，房間 L）
- 空氣砲（第 1 階段）對它無效；只有**鐵塊高速撞它**才會受傷（每次最多扣 3，血量 12；原本 18，鐵塊改成會碎之後調低）
- 它自己提供彈藥：每 4 秒丟出一個鐵塊（場上最多 3 個），落在它附近
- **第 1 階段**：浮在房間中央，每 6 秒轉動整個房間的重力，固定循環：下 → 上 → 下 → 左 → 下 → 右。每次都先回到向下，所以「把鐵塊推到它正下方，等重力轉上」一定有機會；也可以直接對鐵塊放反重力
- **轉向要看得出規律**（2026-10-16 試玩回饋：「看起來是隨機的，只能推過去賭方向」）：
  - 重力時鐘：畫在最下面那排地板上，整個循環排成一排箭頭，框起目前的方向，下一個方向標黃色，下方的條顯示距離下次轉向的時間
  - 王身上的箭頭指向目前的重力方向；轉向前 3 秒改指下一個方向並閃爍、外圈光點越轉越快，另一側顯示倒數 3、2、1
- **第 2 階段**（血量一半以下）：移到天花板（移動中無敵），重力回到向下，但每 7 秒反轉 3 秒——反轉時，它下方的鐵塊會飛上去撞它。這個階段靠近它（4.5 格內，站在最上層平台的內側就打得到）時空氣砲打得到核心（每 0.5 秒最多 1 點）
- **第 2 階段加強**（2026-10-16 試玩回饋：「二階段看起來沒比較強」）：
  - **重力彈幕**：每次重力轉向時射出一圈 10 發受重力影響的紫色子彈（每次角度錯開）。轉上時打向被甩上天花板的玩家，轉回向下時像雨一樣落下。時停可以把子彈凍成踏腳石，空氣砲可以打回去
  - **改丟重裝兵取代鐵塊**（場上最多 2 隻，每 5 秒一隻，只在重力向下時丟）：從魔王正下方往下丟，穿過空隙落到地面，再追著玩家走；不會在平台邊緣掉頭，被擋住會跳過去。不怕摔、空氣砲打不痛，接觸傷害 2
  - **重裝兵也是彈藥**：被甩去高速撞魔王時，魔王扣血（質量 5，一次就是最高的 3），重裝兵碎掉。最直接的打法是把它引到魔王正下方，等重力反轉
  - 為什麼用「不會摔死的兵」：會摔死的兵每次反轉就幾乎全滅，活不到形成威脅，也活不到被拿來當彈藥
  - 瞄準玩家的子彈改成一次 3 發扇形
  - 實測（玩家站著不動）：第一階段約 33 秒倒下，第二階段約 21 秒
- 接觸傷害 2；會發射子彈（可以打回去，但打不痛它）
- 打倒後重力恢復向下，右側的門打開
- 技術：房間的基本重力方向 `fields.base`，所有場域都在它上面疊加；換房間時恢復向下

## 5.6 干擾裝置
目的：每一關大約有兩種解法，但不會有一招在每一關都通用。干擾裝置讓關卡設計者可以「關掉」某條路。

| 裝置 | 顏色 | 範圍內的效果 |
|---|---|---|
| 重力干擾器 | 紫 | 重力場域失效 |
| 時間干擾器 | 藍 | 時間場域失效（包括自身加速） |
| 空間干擾器 | 綠 | 範圍內的傳送門停止運作；閃現不能從範圍內出發或進入範圍 |
| 全能干擾器 | 白 | 全部 |

- 規則（方案 B）：網照樣可以飛進去、展開場域，只是範圍內的部分沒有作用；自身附著的場域進入範圍時也會自然失效
- 分成**固定**與**可移動**兩種，都**無法破壞**
  - 可移動的干擾器和箱子一樣可以推、會被空氣砲推動，也會受**其他顏色**的場域影響（例如重力干擾器可以被時停，但重力場域在它身邊沒有作用）
  - 「怎麼處理干擾器」本身就是謎題，而且需要的能力和被阻擋的能力不同
- 範圍 3 格，以對應顏色的虛線圓表示
- 故事：反派兵器的「規則封印」
- 之後：攜帶干擾器的敵人
- 地圖字元：`1`～`4` 固定、`5`～`8` 可移動，依序為重力、時間、空間、全部

## 5.7 光線
光線不是新能力，而是**被現有能力操縱的對象**，散布在各區域的謎題中。

| 能力或物件 | 對光的影響 |
|---|---|
| 鏡子箱 | 以 `/` 或 `\` 的角度反射；可以推，被空氣砲打到時旋轉 90 度 |
| 傳送門 | 光可以穿過 |
| 點重力、定向重力 | 光線彎曲（重力透鏡）。減重、反重力等倍率型場域不影響光 |
| 減速、強減速 | 在場域邊界折射（光速變慢，司乃耳定律）；角度太大時全反射 |
| 時停 | 光線進入就停住（被吸收） |
| 牆、箱子、干擾器 | 擋住光 |

- **雷射發射器**（`X`）：固定在牆上，背對相鄰的牆持續發光。解謎用，預設**無害**，而且**會穿過玩家**（否則玩家擋在光路上，門會一直開開關關）
- **光線接收器**（`R`）：被照到一次就保持啟動，打開房間的門。原因：玩家走過去時很容易不小心推開鏡子，門又關上
- **雷射兵**（`l`）：會巡邏的敵人
  1. 看到玩家後停下來集氣 2 秒：前 1.6 秒追蹤玩家，最後 0.4 秒鎖定方向（預告線變亮、閃爍）
  2. 發射 0.3 秒的雷射：射程無限，直到被擋住；傷害 1
  3. 冷卻 1.5 秒後回到巡邏
  - 雷射會打傷其他敵人，可以用鏡子、傳送門、重力把它導向別的敵人
  - 被空氣砲打到時會打斷集氣；在時間場域中，整個流程會跟著變慢
- 已驗證：鏡子謎題的實際操作、點重力彎曲、減速折射、時停吸收、雷射兵的時間軸、閃避、友軍傷害

## 5.8 水與溫度
溫度先做成**環境機制**（雷射、冷凍裝置），不是玩家的技能；之後再討論有沒有適合的溫度技能。

### 水（格子水）
- 每一格存一個水量（0～1），每一步依**該格當下的重力方向**往下流、往兩側攤平（Terraria 的做法）。不用粒子系統：結冰、融化都以格為單位，和方格地圖相容
- 和能力的互動

| 能力 | 對水的影響 |
|---|---|
| 反重力 | 場域內的水往上流（實測：水槽裡約 40% 的水往上流出） |
| 無重力 | 水停在半空中 |
| 定向重力 | 水往側面流 |
| 時停 | 水停止流動，而且**變成可以站的實心**（已經泡在裡面的物體不會被封住） |
| 傳送門 | 水從入口流進去、從出口流出來 |
| 光線 | 水的折射率 1.33，光在水面折射 |

- 畫面邊緣對水來說是牆，否則坑底的水會從尖刺下方流光
- 地圖字元：`~` 水、`%` 泡在水裡的尖刺

### 浮力與游泳
- 浮力 = 重力 × 泡水比例 ÷ 密度，方向和當下的重力相反；水中有阻力
- 密度：木箱、鏡子箱 0.5（浮起）、冰塊 0.9、玩家 1.03（約 5 秒沉到 4 格深的池底）、一般敵人 1.3、可移動干擾器 2、重裝兵 3（沉下去）
- 游泳：在水中可以一直按跳躍往上游（每 0.25 秒一次）
- 調整紀錄：原本的水池只有 2 格可游的深度，玩家本身就 2 格高，稍微下沉就碰到池底尖刺；改成 4 格深後，踩水 6 秒不會受傷，也能游過整個水池

### 冰
- **冰牆格**（`I`）：實心、很滑（抓地力 12%）；水遇冷會結成冰牆格
- **冰塊**（`Y`）：和箱子一樣可以推、很滑、大部分沉在水下
- 光線照到冰會被擋住並且升溫，約 1 秒後融化成水（解謎用的無害光線也可以融冰）
- **冷凍裝置**（`C`）：範圍內的水 1 秒後結成冰牆格；有東西在那一格時不會結冰，避免把玩家凍在冰裡

### 熱源
| 熱源 | 地圖字元 | 效果 |
|---|---|---|
| 雷射 | — | 光線經過的**第一個水格**被加熱，加熱強度和熔岩一樣（3 倍），約 0.25 秒後開始沸騰；照到冰會融化。水裡的蒸氣（氣泡）不擋光，避免雷射被自己煮出來的蒸氣擋住 |
| 火爐 | `H` 點燃、`G` 熄滅 | 點燃時範圍內的水沸騰、冰融化；**用空氣砲打它可以點燃或熄滅**（和空氣砲旋轉鏡子同一套規則）；嵌在牆裡（底下是實心牆，水不會從它的位置漏出去） |
| 熔岩 | `Z` | **會流動的液體**（見下方「熔岩」）；碰到會扣血並回到入口；相鄰的水以 3 倍速沸騰、冰融化；冰塊掉進去會融化成水，其他箱子會燒毀，敵人會死 |

### 熔岩
- 原本是固定的地形格子，不受場域影響；改成**會流動的液體**，和水一樣依重力流動，但很黏：流得慢（每步 20%，水是 100%），太薄（不到 1/3 格）就不再往兩側散開，維持成一層
- 受場域影響：反重力往上流、無重力停在半空、減速流得更慢、會穿過傳送門
- **時停的熔岩：實心、可以站，而且不燙**（時間停止，熱就不會傳遞；和時停的水、子彈可以安全踩的規則一致）；場域結束後又會燙
- **碰到水凝固成石頭**（地圖字元 `Q`，實心、永久保留），水變成蒸氣；熔岩太少時只把碰到的水煮成蒸氣
- **遇到冷凍裝置**約 1 秒後凝固成石頭
- 不透光：光線碰到熔岩會被擋住
- 有東西在那一格時不會凝固，避免把玩家封在石頭裡
- 像素版：熔岩也是像素，比水重（會沉到水和蒸氣下面）；水浮在熔岩上方也算碰到，熔岩凝固時上方的水被煮成蒸氣
- **像素版的冰與石頭**（2026-10-15）：也改成像素
  - 冰從**露出的邊緣**逐像素融化；水從**表面**和貼著冰、石頭、牆的地方開始結冰，再往內長
  - 熔岩像素碰到水像素：碰到的地方和周圍一小圈的熔岩變成石頭，水變成蒸氣（只凝固一個像素的話石殼太薄，角色站不上去）；熔岩碰到冰：冰融化成水
  - 角色碰撞仍以格為單位：冰超過半格、石頭超過 1/4 格，整格才對角色是實心的（有東西在那一格時不會變成實心）

### 火山
| 元素 | 地圖字元 | 行為 |
|---|---|---|
| 間歇噴發口 | `!` | 安靜約 4 秒 → 預兆 1 秒（發光、冒火花）→ 噴發 0.8 秒；方向和當下的重力相反；上方被實心（例如石頭）封住時不會噴發；房間的熔岩比基準量多時，會把周圍的熔岩吸回去，避免越積越多 |
| 飛行中的熔岩塊 | — | 每幀噴出兩塊（左右各偏一點），連起來像一根熔岩柱；受重力與時間場域影響、穿過傳送門；**時停時變成可以站、不燙的實心**；**碰到水就在那一格凝固成石頭**；落地後變回熔岩液體 |
| 火山彈 | — | 每次噴發拋出 2 顆，打到玩家或敵人扣 2 點血，落地濺出熔岩；可以用空氣砲打偏、用傳送門轉向 |
| 熔岩源 | `&` | 固定在牆上，往遠離牆的方向持續流出熔岩；出口被封住就停止；空氣砲可以開關 |
| 水源 | `$` | 同上，但流出的是水，預設關閉 |
| 上升的熔岩 | 房間設定 `risingLava` | `{ delay, rowsPerSec, topRow }`：經過 delay 秒後，熔岩從已經有熔岩的地方往上長，到 topRow 停止 |

- **液體總量上限**：熔岩上限 = 一開始的量 + 上升熔岩的量 + 8；水上限 = 一開始的量 + 40。熔岩源、水源、噴發落下的熔岩都不能超過上限（達到上限時熔岩源與水源暫停、不畫液柱，落地的熔岩塊直接冷卻消失）；上升的熔岩只上升一次，加滿預算就停
  - 原因：熔岩源一直流、噴發口又被石頭封住（不再吸回熔岩）時，熔岩會無限增加；加上傳送門把底部的熔岩一直送走，上升的熔岩又不斷補滿底部，就堆成一座熔岩山。實測：放著不動 2 分鐘從 21 增加到 39 且持續增加，修正後停在 33
- 設計紀錄：凍住的熔岩柱原本只是一顆疊一顆的細柱子，像一面牆，玩家站不到中段、頂端又跳不上去；改成每幀噴兩塊（柱子約 20 px 寬），並把時停放低，只凍住下半段，讓頂端在一次跳躍的高度內

### 水蒸氣
- 沿用格子水的系統，每格另外存蒸氣量；方向和重力相反（往上飄），在反重力場域中會往下沉；無重力時停住；時停時凍結；會穿過傳送門
- **膨脹**：1 單位的水沸騰成 4 單位的蒸氣，凝結時反過來，所以總量守恆
  - 原因：原本 1:1 時蒸氣太稀，一擴散就低於門檻、立刻凝結回水，幾乎沒有作用
- **上升速度約每秒 3 格**（原本約每秒 14 格，一冒出來就衝到天花板），加上隨機的左右飄動，看起來在翻騰；擴散較少，會維持成一團往上飄，約 5 秒後散去
  - 調整過程：只降低上升速度時，蒸氣在路上橫向擴散得太稀，2.5 秒就凝結光了，所以同時減少橫向擴散
- 會慢慢凝結回水落下（每秒約 8%）；在冷凍裝置附近凝結得很快；**碰到天花板時凝結速度 6 倍**，否則蒸氣會一直聚積在天花板下方
- **擋住光線**：濃度超過門檻時，雷射會被擋住，可以當成對付雷射兵的煙幕
- **不會燙傷**（先保持單純）
- 一般物體和玩家都**不會被蒸氣推動**，只有特殊的**蒸氣浮台**會
- 實作細節：太稀的水或蒸氣不會被直接刪除，而是先累積起來，夠多時再變回水，否則水會越來越少

### 畫面回饋
- 加熱中的水格會冒泡，越接近沸騰泡泡越多（原本加熱時畫面沒有變化，很容易以為雷射沒有作用）

### 除錯
- 按住 **B** 在游標位置噴蒸氣、按住 **N** 倒水；除錯面板（F2）的「水與蒸氣」分頁可以即時調整上升速度、飄動、集中程度、凝結速度、沸騰速度、浮台速度等

### 蒸氣機關
- **蒸氣浮台**（`U`，連續的 U 合成一個）：**下方一格**有蒸氣時被推上去，沒有就落下（只看下方：到頂時周圍聚積的蒸氣不算）；載著站在上面的東西移動；上面的東西被天花板擋住時會停下，不會把玩家擠進天花板
- **蒸氣渦輪**（`W`）：**從下方冒上來**的蒸氣碰到時啟動（上方飄過來的不算），啟動過一次就保持啟動，用來開門

### 之後
- 溫度技能：再討論

## 5.9 水的實驗版本（比較用）
為了比較不同的水，同時保留四個版本，遊戲本體共用，只換掉水的部分：

| 版本 | 網址參數 | 程式位置 | 做法 |
|---|---|---|---|
| 原版 | （無） | `js/water.js` | 格子水 |
| 粒子版 | `?water=particle` | `experiments/particle-water/` | 粒子模擬水流（雙密度鬆弛 SPH），每幀把粒子換算回「每格水量」，所以浮力、游泳、折射、結冰、蒸氣、傳送門都沿用原版；蒸氣仍是格子 |
| 原版＋粒子特效 | `?water=fx` | `experiments/water-fx/` | 運作完全是原版，畫面加上往下流的水珠、落水的水花、物體落水的大水花、水面波紋 |
| Noita 風像素水 | `?water=pixel` | `experiments/pixel-water/` | 落沙模擬：畫面切成 2×2 px 的小格（320×176），水往下 → 斜下 → 往兩側散開；蒸氣往上飄、左右飄動、慢慢凝結；**水和蒸氣都是像素**。每幀換算回每個大格的水量與蒸氣量，其他系統沿用 |

- 開始畫面可以切換版本，畫面左上角顯示目前的版本
- 粒子版調整紀錄
  - 壓力太弱時水被壓縮到一半的高度；壓力太強時粒子劇烈抖動。改成每幀 3 個小步驟、每步 3 次輕推，水面高度只差 2 px，靜止後完全不抖
  - 一開始粒子隨機放在格子裡會互相重疊，房間一載入水就炸開；改成平均排列，並在載入時先在背景讓水穩定下來
  - 效能：約 500 顆粒子每幀約 1.7 ms（預算 16.7 ms）；房間載入的第一幀約 0.2 秒
- 像素版
  - 粒子版看起來是一群泡泡，因為它模擬的是互相推擠的圓球；Noita 的效果來自落沙模擬，所以另外做成第四個版本
  - 重力、時間場域每個 16 px 大格只取樣一次，小格共用；時間變慢時像素「有機率」不動，時停時凍結
  - 實心物件會把水擠開，所以物件內部沒有水像素；浮力改看物件兩側外面同一高度有沒有水
  - 效能：整個畫面每幀約 1 ms；水面高度和原版完全一樣
- 粒子版和原版的差異（實測）：雷射從上方煮水，粒子版較慢；從側面煮水，粒子版較快；側壁傳送門排水，粒子版較慢

## 6. 原型規格

### 6.1 基本數值
| 項目 | 值 |
|---|---|
| 畫面解析度 | 640×360，等比例放大 |
| 每格大小 | 16 px（畫面約 40×22 格） |
| 角色大小 | 約 1 格寬 × 2 格高 |
| 一般跳躍高度 | 約 3 格 |
| 網的射程 | 約 10 格 |

### 6.2 規則
- 鏡頭：洛克人式的固定畫面房間，走到邊緣時切換房間
- 死亡與重生：掉進坑或碰到尖刺會扣血，並回到房間入口，房間內的物件同時重置
- 箱子：可以推、不能拿起來、可以疊放
- **尖刺對箱子是實心的**：箱子會停在尖刺上把它蓋住，玩家可以踩著箱子走過；敵人碰到尖刺仍然會死
- **箱子生成器**（地圖字元 `@`）：房間載入時生成一個箱子；箱子離開生成點（1.5 格以上）或消失後，1 秒後補一個新的。同一個生成器的箱子最多 4 個，超過時最舊的會消失。生成點有東西（包括玩家）時會等待
- 原型先不做：斜坡、網黏在敵人身上、技能樹介面、空間技能（M7 才做）

### 6.3 美術（像素風，2026-10-15 開始，做法參考 GriMon）
- **像素單位**：1 世界像素 = 1 像素。整個遊戲畫在 640×360 的低解析度畫布上，最後以**整數倍**放大到螢幕（依裝置像素計算；視窗太小才用小數倍），關閉平滑（`imageSmoothingEnabled = false`、`image-rendering: pixelated`），座標一律取整數
- **畫法**：用整數像素緩衝逐點畫；資料是「字元點陣圖＋調色盤」（`.` 為透明）或由程式繪製（四肢、團塊、雜訊），最後自動加 1 px 深色外描邊；第一次用到時烘焙成小畫布並快取，每幀只貼圖；另外烘焙一張全白剪影，受擊時閃白
- 主角：16×32 格（碰撞框 12×28，腳底對齊）；動畫：待機 2 格、跑步 4 格、跳躍、落下；腳一律朝向重力方向（重力反轉就倒立、側向重力轉 90 度）；砲管逐像素畫，跟著滑鼠轉動
- 敵人：步行兵、跳躍兵、飛行兵、重甲兵、砲台、雷射兵各兩格動畫，面向移動方向
- 地形：牆用雜訊上色（4 種變化依位置挑選），格子之間沒有接縫，只有外露的邊描邊、上緣加亮；尖刺、門、箱子都是像素圖
- 文字：Fusion Pixel 12px 繁中像素字型（OFL 授權，`fonts/`），畫布上只用 12px 一種大小才清楚；DOM 面板（說明、裝備、選關）暫時維持原本的字型
- 場域顏色：重力＝紫、時間＝藍、空間＝綠（半透明）
- 畫面和碰撞分開：碰撞框固定，圖片只是貼在上面
- 尚未改成像素圖：開關、機關（刀片、壓碎機、移動平台）、噴發口、液體源、鏡子、干擾器、光線、場域外框

### 6.4 技術

### 7.8 機關的視覺標示
| 機關 | 圖案 | 規則 |
|---|---|---|
| 鑰匙箱 | 箱子上畫**鑰匙** | 只有它能啟動「鎖」開關 |
| 鎖開關 | 開關上畫**鎖** | 只對鑰匙箱有反應 |
| 一般壓板 | 素面壓板 | 任何有重量的東西都能啟動（玩家、箱子、敵人） |
| 門 | 畫上和開關相同的圖案 | 和開關之間畫一條線，啟動時線會亮起 |

- 同一個房間有多組開關時，用顏色區分（例如紅鑰匙對紅鎖、藍鑰匙對藍鎖）
- 開關被壓下時要有明顯的回饋：亮燈、音效，門的方向出現光線
- 之後如果做質量技能，可以加入「需要足夠重量才會啟動」的重壓板

### 測試用敵人
| 敵人 | 用來驗證 |
|---|---|
| 步行兵 | 用重力讓它浮起，或讓它掉進坑裡 |
| 跳躍兵 | 低重力讓它跳得更高（雙面刃效果） |
| 飛行兵 | 反重力或強重力會不會讓它墜落 |
| 砲台 | 子彈被減速或停住，甚至可以踩上去 |
| 重裝兵 | 一般攻擊打不動，必須靠能力處理 |

### 試玩的檢查問題
- 發射場域的手感是否流暢，會不會打斷戰鬥節奏？
- 玩家能不能一眼看懂場域的效果？
- 有沒有一招就能解掉所有謎題的情況？
- 場域邊界會不會出現物件抖動或穿牆？

## 9. 故事設定

### 9.1 基本設定
- 王道奇幻故事：主角是**勇者轉世**，和**掌管世界規則的女神們**一起對抗反派
- 女神的力量被反派封印在**兵器**（魔王）中；擊敗魔王就能取回力量，也就是新的能力型態
- 魔王戰中，魔王會使用體內封印的能力攻擊玩家，讓玩家先體驗過，再取得那個能力

| 故事元素 | 對應的遊戲系統 |
|---|---|
| 世界規則 | 物理常數（重力、時間、空間） |
| 力量被封印 | 玩家一開始沒有能力 |
| 女神的力量 | MP |
| 網 | 「規則之線」：把新規則織進世界 |
| 女神重新編織力量 | 技能重置 |

### 9.2 女神
- 有多位女神，例如**時空雙子女神**（時間、空間）、**重力女神**，可能還有一位**掌管所有規則的源頭**
- 名字為**原創**，以神話作為字根（候選名稱見 9.5）
- 她們是同伴，但平常不出現：力量寄宿在主角身上
- 出現的時機：劇情的關鍵時刻、取回力量時、在神殿配點與重置時、第一次遇到新機制時；施放技能時可以短暫顯示剪影或光效

### 9.3 反派
- **表面上**：奪走女神的力量，想成為新的規則制定者
- **真相**：想**讓世界永遠停止**，而且有兩層理由
  - 個人：他失去了重要的人
  - 世界：世界本身正在走向毀滅
- 灰色地帶：他的做法不完全是錯的，所以最後主角和女神必須提出另一個答案
- 伏筆（用環境敘事表現，不靠大量對話）
  - 時間區凍結的城鎮是他過去生活的地方，城裡有一個不斷重複的場景
  - 他的兵器與其說是攻擊，更像是在守護某個地方
  - 他從來沒有真正想殺死主角，每次都只是阻止主角

### 9.4 世界結構
- 力量被奪走後，各區域的規則已經壞掉，區域主題本身就是謎題
  - 重力區：浮空島、往上掉的岩石、倒流的瀑布
  - 時間區：凍結的城鎮、時間循環、時快時慢的機關
  - 空間區：房間之間連接錯亂
- 中央是女神神殿（存檔、技能重置、劇情推進），三種力量都取回後才能進入反派城堡

```
            [空間區]
               │
[重力區] ── [女神神殿] ── [時間區]
               │
            [反派城堡]
```

### 9.5 已定案
- 時空雙子女神：**凱洛菈**（時間，字根 Kairos）、**卡蒂雅**（空間，字根 Cardea）
  - 注意：《欲神幻想》中已經有名為「卡蒂雅」的角色（設定是女神的轉生宿體），之後可以考慮微調用字
- 反派是**前世勇者的同伴**；他失去的重要的人，就是前世的勇者
- 反派的完整動機：世界的規則之線正在磨損 → 第一次崩壞事件中失去了前世的勇者 → 決定讓世界永遠停止，不再有人失去什麼 → 主角與女神要提出第三個答案：重新編織規則

### 9.6 命名候選（其他角色）
共同主題：女神透過「編織」來掌管規則，和網＝規則之線的設定一致（北歐的諾倫、希臘的命運三女神都是紡線的女神）。

| 角色 | 神話字根 | 候選名稱 |
|---|---|---|
| 時間女神 | Kairos（關鍵的瞬間）、Chronos（流逝的時間）、Verðandi（現在） | 凱洛菈、克羅妮亞、薇妲 |
| 空間女神 | Cardea（門樞）、Chaos（虛空）、《尸子》的「宇」 | 卡蒂雅、卡歐絲 |
| 重力女神 | Gaia（大地）、Ma'at（天秤與秩序） | 蓋菈、瑪緹 |
| 規則的源頭 | Ananke（必然、自然法則） | 安娜琪 |
| 時間技能名稱（彩蛋） | 諾倫三女神：烏爾德（過去）、薇兒丹蒂（現在）、詩寇蒂（未來） | 對應倒轉、時停或減速、加速 |

- 定案前要先搜尋有沒有和其他作品撞名（例如東方 Project 已經有「赫卡提亞」，所以避開 Hecate 的直接變化）
